# 3WNCROD-Thesis

This repository contains the research implementation and data for the 3WNCROD thesis project. It includes both the original 3WNCROD work and an expanded 3WNCROD+ implementation, along with datasets and supporting files.

## Repository structure

- `1. 3WNCROD/`
  - Original implementation, notebooks, MATLAB/Python code, and datasets used for the base 3WNCROD study.
- `2. 3WNCROD+/`
  - Extended implementation with additional experiments, notebook iterations, and dataset variants for the improved 3WNCROD+ approach.
- `3.Datasets/`
  - Shared datasets used across the project.
- `3WNCROD-2024.pdf`
  - Thesis or project report document.
- `main.py`
  - Entry point script for the repository (if applicable).

## Purpose

The repo is designed to support thesis research by organizing experiments, code, and datasets in a clear way. It is meant for running, reviewing, and comparing 3WNCROD and 3WNCROD+ results.

## Notes

- Most of the work is stored as Jupyter notebooks and MATLAB/Python source files.
- Datasets are included for reproducibility and analysis.
- Use the notebooks in each folder to explore the implementation and results.
